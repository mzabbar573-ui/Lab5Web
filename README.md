# Praktikum 5 — JavaScript Dasar dan Manipulasi HTML

## 1. Tujuan Praktikum

Praktikum ini bertujuan untuk memahami dasar-dasar JavaScript dan penerapannya pada halaman HTML. Melalui praktikum ini, mahasiswa mempelajari penggunaan variabel, operator, percabangan, perulangan, fungsi, manipulasi elemen HTML, serta validasi formulir.

## 2. Teori Dasar

JavaScript merupakan bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif. JavaScript dapat menerima input dari pengguna, melakukan perhitungan, memproses data, dan mengubah tampilan halaman HTML.

Materi teori dasar yang dipelajari meliputi:

- **Variabel:** menyimpan data menggunakan `let` dan `const`.
- **Tipe data:** mengenal data seperti string, number, dan boolean.
- **Operator:** melakukan operasi aritmatika dan perbandingan.
- **Percabangan:** menggunakan `if-else` untuk menentukan kondisi.
- **Perulangan:** menggunakan perulangan untuk menjalankan instruksi berulang kali.
- **Function:** membuat fungsi agar kode dapat digunakan kembali.
- **Manipulasi HTML:** memilih dan mengubah elemen HTML menggunakan JavaScript.
- **Event:** menjalankan kode ketika pengguna melakukan tindakan, seperti menekan tombol.
- **Validasi input:** memeriksa data yang dimasukkan pengguna.

## 6. Cara Menjalankan Program

1. Siapkan file `index.html` dan `script.js`.
2. Pastikan kedua file berada di dalam folder proyek yang sama.
3. Pastikan file HTML memanggil JavaScript menggunakan kode berikut:

   ```html
   <script src="script.js"></script>
   ```

4. Buka folder proyek menggunakan Visual Studio Code.
5. Jalankan `index.html` menggunakan ekstensi Live Server atau buka langsung melalui browser.
6. Uji setiap latihan dengan memasukkan data dan menekan tombol yang tersedia.
7. Ambil screenshot hasil pengerjaan dan simpan sesuai nama file pada bagian screenshot.
